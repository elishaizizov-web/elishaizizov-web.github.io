🔑 GitHub-Token (für Bildupload)
So erstellen Sie ein Token:
1. Gehen Sie zu github.com und melden Sie sich an.
2. Klicken Sie auf Ihr Profilbild → Settings → Developer settings → Personal access tokens → Tokens (classic).
3. Klicken Sie Generate new token (classic), wählen Sie repo und generieren Sie den Token.
4. Kopieren Sie den Token und fügen Sie ihn oben ein.
